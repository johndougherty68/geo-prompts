## How to use these

1. Open the prompt, copy the box, fill in the [BRACKETS].
2. Fresh chat, web search on.
3. Run it 3 times per engine before you believe a result.

Every prompt file includes its own rules and limits. Read them; a manual run is a snapshot, not a trend.
